# Daily Notes

Notas diarias. Obsidian puede crearlas automáticamente con el plugin "Daily Notes" (activado por defecto).

## Uso típico

- Ideas sueltas que te vienen durante el día
- Registro de lo que has hecho / decidido
- Log de conversaciones importantes
- Lecturas del día

## Formato

`YYYY-MM-DD.md` — una nota por día.

## Cierre de sesión

Cuando usas `/cierre` con Claude, si hay cosas sueltas sin destino claro, puede guardarlas aquí con la fecha del día.
