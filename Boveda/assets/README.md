# Assets

Multimedia: imágenes, PDFs, capturas, documentos anexos a notas.

## Organiza como quieras

Algunos ejemplos:

- `assets/imagenes/`
- `assets/pdfs/`
- `assets/capturas/`
- `assets/multimedia/`

Obsidian automáticamente guarda aquí imágenes que pegues en notas (configurable en Settings → Files & Links).

## Nota sobre Git

Si el archivo es pesado (>10 MB), piensa si quieres subirlo al repo o mantenerlo solo local. El `.gitignore` ya excluye vídeos y audio pesados por defecto.
