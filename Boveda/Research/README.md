# Research

Investigaciones, lecturas largas, referencias que NO pertenecen a un proyecto específico.

## Qué va aquí

- Artículos/libros que estás leyendo con notas
- Comparativas de herramientas
- Ideas conceptuales a largo plazo
- Referencias técnicas que usas como documentación

## Qué NO va aquí

- Tareas de proyectos → `Proyectos/<proyecto>/`
- Notas sueltas rápidas → `Daily Notes/` o `pendientes-claude/notas-sueltas/`
- Capturas web recientes → `pendientes-claude/clips-web/` (se clasifican después)
