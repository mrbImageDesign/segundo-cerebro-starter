# Personal

Carpeta para tu información personal. Claude la respeta como privada — no se sube a ningún servidor externo.

## Sugerencias de subcarpetas (añade las que te sirvan)

- `FINANZAS/` — ingresos, gastos, inversiones
- `SALUD/` — analíticas, medicaciones, suplementos
- `LOGISTICA/` — mudanzas, viajes, trámites
- `Vehiculo/` — coches, mantenimientos
- `Documentos/` — escrituras, contratos, identificaciones (escaneados)
- `Cursos/` — cursos que estás haciendo

Empieza sin subcarpetas y crea las que vayas necesitando. No es una obligación tenerlas todas.
